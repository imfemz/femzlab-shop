Pour les débutants et les intermédiaires. Les techniques sont celles des professionnels, expliquées pour quelqu'un qui démarre sur After Effects.

Adobe After Effects : toute la formation est tournée dessus. Pour le tracking, Mocha AE est fourni avec After Effects. Le module 3D, lui, s'appuie sur un plugin payant — voir la question suivante.

Non. Le module 3D s'appuie sur Element 3D, un plugin de Video Copilot, payant et vendu séparément. Il n'est pas inclus dans la formation — je préfère te le dire avant que tu achètes.
